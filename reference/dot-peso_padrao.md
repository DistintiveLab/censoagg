# Coluna de peso padrao por dataset de microdados

Coluna de peso padrao por dataset de microdados

## Usage

``` r
.peso_padrao(dataset)
```

## Arguments

- dataset:

  `"pessoas"`, `"domicilios"` ou `"familias"`.

## Value

Nome da coluna de peso (PESO_PES/PESO_DOM/PESO_FAM) ou `NULL` para
dataset desconhecido (a autodeteccao cuida do resto).
