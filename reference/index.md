# Package index

## Agregacao

Leem o Censo via censobr e devolvem lista nomeada variavel -\>
long(local, periodo, valor), pronta para o DW.

- [`agregar_setores()`](https://distintivelab.github.io/censoagg/reference/agregar_setores.md)
  : Agrega os agregados por setor censitario do Censo
- [`agregar_microdados()`](https://distintivelab.github.io/censoagg/reference/agregar_microdados.md)
  : Agrega microdados do Censo por territorio

## Dicionario

Escolha de variaveis sem depender do censobr em runtime.

- [`censo_variaveis()`](https://distintivelab.github.io/censoagg/reference/censo_variaveis.md)
  : Dicionario de variaveis do Censo (snapshot offline)
- [`dict_tracts_2022`](https://distintivelab.github.io/censoagg/reference/dict_2022.md)
  [`dict_microdata_2022`](https://distintivelab.github.io/censoagg/reference/dict_2022.md)
  : Snapshots dos dicionarios do Censo 2022
